# 사용자 가이드

인턴핑은 Microsoft Teams 안에서 인턴의 일정을 확인하고 투입 예약을 관리하는 탭 앱입니다. 이 문서는 화면에서 실제로 조작하는 방법을 다룹니다. 사용할 수 있는 기능의 범위와 역할별 권한 전체 표는 [주요 기능](./features.md#역할별-기능)에서 확인하세요.

사용하는 환경을 선택하세요. 선택한 화면은 페이지 주소에 유지되므로 같은 PC 또는 모바일 가이드 화면을 다른 사용자에게 공유할 수 있습니다.

## 메인 화면 살펴보기

앱을 열면 **주간 보기**가 기본으로 표시됩니다. 각 행은 인턴을, 각 열은 날짜를 나타내므로 비어 있는 날짜와 기존 투입 일정을 쉽게 비교할 수 있습니다.

1. 이전·다음 버튼으로 표시 기간을 이동합니다.
2. **주간** 또는 **월간** 보기를 선택합니다.
3. 상태 필터에서 확정, 승인 대기, 보류, 반려 일정을 표시하거나 숨깁니다.
4. 대상자 필터에서 특정 인턴의 일정만 선택합니다.
5. 일정을 선택해 제목, 기간, 장소, 주최자, 대상자와 상태를 확인합니다.

화면이 좁으면 캘린더 격자 대신 날짜별 목록이 표시됩니다. 일정 상세는 슬라이드 패널로 열립니다.

![캘린더, 필터, 승인 대기 목록, 일정 상세, 업로드와 투입 예약 버튼을 표시한 인턴핑 메인 화면](/img/user-guide/ko/00-overview.png)

*메인 화면에서 캘린더, 필터, 승인 대기 목록과 일정 상세를 확인합니다.*

## 일정 추가하기

1. **투입 예약**을 선택합니다. 관리자에게는 **일정 만들기**로 표시됩니다.
2. 일정 제목을 입력합니다.
3. 필요하면 설명과 장소를 입력합니다.
4. 교육, 해커톤/고객사, 미팅, 업무 지원, 휴가/부재, 기타 중 분류를 선택합니다.
5. 시작일과 종료일을 지정합니다.
6. 시간 일정이면 시작·종료 시간을 입력하고, 종일 일정이면 두 필드를 비워 둡니다.
7. 일정 대상자를 한 명 이상 선택합니다.
8. 내용을 확인하고 저장합니다.

일반 사용자가 만든 일정은 **승인 대기**로 저장됩니다. 관리자가 만든 일정은 즉시 **확정**됩니다.

대상자에게 겹치는 확정 일정이 있으면 충돌 안내가 표시됩니다. 판정 기준은 [중복 투입 확인](./features.md#중복-투입-확인)을 참고하세요.

*투입 내용을 입력하고 대상자를 선택한 뒤 예약을 신청합니다.*

## 일정 필터링하기

캘린더에 표시할 일정을 처리 상태와 대상자 기준으로 좁힐 수 있습니다. 두 필터는 함께 적용됩니다.

### 상태별로 필터링하기

상태 버튼을 하나 이상 선택하면 확정, 승인 대기, 보류 또는 반려 일정만 볼 수 있습니다. 활성화된 상태를 다시 선택하면 필터에서 제외됩니다.

![확정, 승인 대기, 보류 및 반려 상태 필터를 강조한 인턴핑 주간 보기](/img/user-guide/ko/02-1-filter-status.png)

*상태 필터를 사용해 필요한 처리 상태의 일정만 확인합니다.*

### 인턴별로 필터링하기

인턴 선택 메뉴를 열고 전체 또는 한 명을 선택합니다. 캘린더에는 선택한 대상자의 일정만 표시됩니다.

![인턴 선택 필터를 강조한 인턴핑 주간 보기](/img/user-guide/ko/02-2-filter-intern.png)

*인턴 필터를 사용해 한 명의 일정에 집중할 수 있습니다.*

## 일정 관리하기

관리자는 모든 일정을 수정하거나 삭제할 수 있습니다. 일반 사용자는 본인이 신청했고 아직 확정되지 않은 일정만 수정할 수 있습니다. Outlook에서 가져온 일정의 대상자는 본인 일정을 제거할 수 있습니다. 여러 대상자가 함께 등록된 일정에서는 현재 사용자만 대상자에서 제외됩니다.

변경 내용은 다른 사용자의 열린 화면에 실시간으로 전송되지 않습니다. 다른 사용자의 변경이 보이지 않으면 표시 기간을 이동하거나 페이지를 새로 고침합니다.

### 일정 삭제하기

일정을 선택하고 상세 내용을 확인한 뒤 휴지통 아이콘을 사용합니다. 서버가 사용자 역할과 일정 소유권을 확인한 뒤 일정 전체를 삭제하거나 현재 대상자만 제외합니다.

![선택한 일정과 상세 패널의 휴지통 아이콘을 강조한 인턴핑 화면](/img/user-guide/ko/03-delete-schedule.png)

*삭제 권한이 있을 때 일정 상세 패널에 휴지통 아이콘이 표시됩니다.*

### 일정 수정하기

캘린더 또는 승인 대기 목록에서 수정 가능한 일정을 선택한 뒤 상세 패널의 연필 아이콘을 사용해 입력창을 다시 엽니다.

![승인 대기 일정과 상세 패널의 연필 아이콘을 강조한 인턴핑 화면](/img/user-guide/ko/04-edit-schedule.png)

*수정 권한이 있을 때 연필 아이콘으로 일정 입력창을 다시 열 수 있습니다.*

## 추가 기능

### 일정 검토 및 승인하기

관리자 화면 오른쪽의 **승인 대기** 패널에는 아직 처리하지 않은 신청이 건수와 함께 표시됩니다. 캘린더에서 직접 승인 대기 일정을 선택해도 됩니다.

1. **승인 대기** 목록 또는 캘린더에서 검토할 일정을 선택합니다.
2. **일정 상세**에서 기간, 분류, 대상자와 요청자를 확인합니다.
3. 필요하면 대상자의 기존 확정 일정과 겹치는지 캘린더에서 함께 확인합니다.
4. **승인/보류 사유** 입력란에 처리 사유를 적습니다. 입력하지 않아도 처리할 수 있습니다.
5. **승인**, **보류**, **반려** 중 하나를 선택합니다.

| 처리 | 결과 |
| --- | --- |
| 승인 | 팀 캘린더에서 확정 일정으로 처리됩니다. |
| 보류 | 추가 정보나 조율을 기다리는 상태로 남습니다. 나중에 다시 승인하거나 반려할 수 있습니다. |
| 반려 | 투입 예약이 거절됩니다. |

처리 버튼은 관리자에게만 표시되며 승인 대기 또는 보류 상태의 일정에서만 사용할 수 있습니다. 신청, 수정, 승인, 보류, 반려와 삭제 기록은 일정 이력에 남습니다. 처리 결과가 Teams 메시지나 이메일로 자동 발송되지는 않습니다.

![승인 대기 목록과 일정 상세의 사유 입력란, 승인·보류·반려 버튼을 표시한 인턴핑 관리자 화면](/img/user-guide/ko/07-approval.png)

*승인 대기 일정을 선택하면 상세 아래에 사유 입력란과 승인·보류·반려 버튼이 표시됩니다.*

### 일정 알림 받기

인턴핑에는 **채팅** 탭이 함께 설치됩니다. 본인이 대상자로 지정된 일정이 바뀌면 인턴핑이 이 대화로 알림 메시지를 보냅니다. 알림을 받기 위해 따로 설정할 내용은 없습니다.

| 알림 | 보내는 시점 |
| --- | --- |
| 새 일정이 배정되었습니다. | 본인이 대상자로 포함된 일정이 만들어졌을 때 |
| 일정이 변경되었습니다. | 배정된 일정의 내용이 수정되었을 때 |
| 일정 담당에서 제외되었습니다. | 배정된 일정이 삭제되었거나 대상자에서 빠졌을 때 |

각 메시지에는 일정 제목과 분류, 날짜와 시간, 처리한 사람이 함께 표시됩니다. 배정과 변경 알림의 **Outlook에 추가**를 선택하면 해당 일정을 ICS 파일로 바로 내려받을 수 있습니다.

이미 Outlook에 넣어 둔 일정이 변경되면 기존 항목을 지우고 다시 추가합니다. 일정이 삭제된 경우에는 Outlook에서 직접 지웁니다. 승인, 보류, 반려 결과는 알림으로 발송되지 않습니다.

![새 일정 배정, 일정 변경, 담당 제외 알림과 Outlook에 추가 링크를 표시한 인턴핑 채팅 화면](/img/user-guide/ko/09-bot-notifications.png)

*채팅 탭에서 배정, 변경, 제외 알림을 확인하고 Outlook에 추가할 수 있습니다.*

### Outlook 일정 업로드하기

현재 화면에서 **일정 업로드** 버튼은 인턴에게 표시됩니다. 인턴이 업로드한 일정은 항상 본인에게 배정됩니다. 서버 API는 관리자가 선택한 대상자에게 업로드하는 기능도 지원하지만 현재 관리자 화면에는 업로드 버튼이 없습니다.

1. 준비한 Outlook `.sql` 파일을 선택합니다.
2. 찾은 일정 수와 제목별 미리보기를 확인합니다.
3. 기본 선택 상태를 확인합니다. 등록된 팀원이 주최한 일정은 선택되고 외부 주최 일정은 처음에 제외됩니다.
4. 가져오지 않을 제목을 해제하거나 필요한 외부 일정을 다시 선택합니다.
5. 업로드를 실행하고 생성, 병합, 중복, 형식 오류와 제외 건수를 확인합니다.

한 번에 최대 4MB 또는 1,000건까지 처리합니다. 중복 일정 병합 기준과 SQL 처리 방식은 [Outlook SQL 일정 업로드](./features.md#outlook-sql-일정-업로드)를 참고하세요.

:::warning[`requested_by` 필드]
`requested_by`에는 Outlook 주최자의 이름이나 이메일을 사용합니다. 다른 데이터베이스에서 복사한 사용자 GUID는 인턴핑 사용자와 연결할 수 없습니다.
:::

## Outlook에 일정 추가하기

1. 캘린더에서 일정을 선택합니다.
2. 상세 패널의 **Outlook에 추가 (.ics)**를 선택합니다.
3. 내려받은 `.ics` 파일을 엽니다.
4. Outlook에서 저장할 캘린더를 확인한 뒤 저장합니다.

이 기능은 수동 파일 내보내기이며 Outlook 자동 또는 양방향 동기화가 아닙니다. 파일에 담기는 정보와 시간대 처리는 [Outlook용 ICS 내보내기](./features.md#outlook용-ics-내보내기)를 참고하세요.

*Outlook에 추가를 선택하면 현재 일정을 ICS 파일로 내려받습니다.*

## 사용자 역할 관리하기

**사용자 관리** 버튼은 관리자에게만 화면 오른쪽 위, **일정 만들기** 왼쪽에 표시됩니다.

1. 관리자 계정으로 오른쪽 위 **사용자 관리**를 선택합니다.
2. 목록에서 대상 사용자를 이름 또는 이메일로 찾습니다. 본인 계정에는 **나** 표시가 붙습니다.
3. 사용자 오른쪽의 **관리자**, **팀원**, **인턴** 중 지정할 역할을 선택합니다. 현재 역할이 강조 표시됩니다.
4. 강조 표시가 선택한 역할로 바뀌었는지 확인하고 창을 닫습니다.

| 역할 | 권한 요약 |
| --- | --- |
| 관리자 | 모든 일정 생성·수정·삭제, 승인·보류·반려, 사용자 역할 지정 |
| 팀원 | 투입 예약 신청, 본인이 신청한 미확정 일정 수정·삭제 |
| 인턴 | 팀원 권한에 더해 Outlook SQL 일정 업로드 |

역할 변경은 즉시 적용되지만 대상 사용자의 화면에는 실시간으로 반영되지 않습니다. 해당 사용자가 페이지를 새로 고쳐야 바뀐 권한이 보입니다.

마지막 관리자와 `ADMIN_EMAILS`에 지정된 계정은 앱 화면에서 관리자 권한을 제거할 수 없습니다.

![사용자 목록과 관리자·팀원·인턴 역할 버튼을 표시한 인턴핑 사용자 관리 창](/img/user-guide/ko/08-user-role.png)

*사용자 관리 창에서 각 사용자에게 관리자, 팀원 또는 인턴 역할을 지정합니다.*

## 상태 알아보기

| 상태 | 의미 | 다음 행동 |
| --- | --- | --- |
| 승인 대기 | 관리자가 아직 결정하지 않음 | 관리자 검토를 기다립니다. |
| 확정 | 투입 일정이 승인됨 | 팀 일정으로 사용하거나 Outlook으로 내보냅니다. |
| 보류 | 정보 또는 일정 조율이 필요함 | 관리자에게 필요한 내용을 확인합니다. |
| 반려 | 투입 예약이 거절됨 | 처리 사유를 확인하고 필요하면 다시 신청합니다. |

## 문제 해결

- **일정이 보이지 않음:** 표시 기간, 상태 필터와 대상자 필터를 확인합니다.
- **수정 버튼이 없음:** 일반 사용자는 확정된 일정을 수정할 수 없습니다.
- **업로드 버튼이 없음:** 현재 화면에서는 인턴 계정에만 Outlook SQL 업로드가 표시됩니다.
- **Outlook에 자동 반영되지 않음:** 내려받은 ICS 파일을 열어 Outlook에 직접 저장합니다.
- **다른 사용자의 변경이 보이지 않음:** 실시간 동기화가 없으므로 페이지를 새로 고침합니다.
- **사용자 전환 메뉴가 표시됨:** Entra 설정이 없는 무인증 개발 모드입니다. 운영 서버에서 사용하면 안 됩니다.

## 일정 추가하기 \{#mobile-add-schedule}

1. **+ 투입 예약**을 누릅니다.
2. 제목과 필요한 설명·장소를 입력합니다.
3. 분류, 시작일과 종료일, 필요한 경우 시간을 지정합니다.
4. 대상자를 한 명 이상 선택합니다.
5. 내용을 확인한 뒤 신청합니다.

일반 사용자의 신청은 **승인 대기**로 저장되고 관리자가 만든 일정은 바로 **확정**됩니다. 일정 중복 경고도 PC와 같은 기준으로 표시됩니다.

![인턴핑 모바일 투입 예약 입력 방법](/img/user-guide/ko/mobile/01-add-schedule.png)

*입력창을 순서대로 작성한 뒤 투입 예약을 신청합니다.*

상세 패널의 휴지통 아이콘을 누르고 삭제를 확인합니다. 여러 대상자가 있는 Outlook 가져오기 일정은 적용되는 권한 규칙에 따라 현재 대상자만 제외될 수 있습니다.

## 추가 기능 \{#mobile-extra}

### 일정 검토 및 승인하기 \{#mobile-approval}

관리자는 승인 대기 수를 확인해 검토가 필요한 요청을 찾을 수 있습니다. 승인 대기 또는 보류 일정을 열고 내용과 대상자를 확인한 뒤 승인, 보류 또는 반려합니다. 처리 이력과 권한 규칙은 PC와 같습니다.

### 일정 알림 받기 \{#mobile-notifications}

Teams 모바일에서도 인턴핑 **채팅**에서 같은 알림을 받습니다. 본인이 대상자로 지정된 일정이 바뀌면 알림 메시지가 오며 받기 위해 따로 설정할 내용은 없습니다.

| 알림 | 보내는 시점 |
| --- | --- |
| 새 일정이 배정되었습니다. | 본인이 대상자로 포함된 일정이 만들어졌을 때 |
| 일정이 변경되었습니다. | 배정된 일정의 내용이 수정되었을 때 |
| 일정 담당에서 제외되었습니다. | 배정된 일정이 삭제되었거나 대상자에서 빠졌을 때 |

각 메시지에는 일정 제목과 분류, 날짜와 시간, 장소와 처리한 사람이 함께 표시됩니다. 배정과 변경 알림의 **Outlook에 추가**를 누르면 해당 일정을 ICS 파일로 바로 내려받을 수 있습니다.

이미 Outlook에 넣어 둔 일정이 변경되면 기존 항목을 지우고 다시 추가합니다. 일정이 삭제된 경우에는 Outlook에서 직접 지웁니다. 승인, 보류, 반려 결과는 알림으로 발송되지 않습니다.

![새 일정 배정, 일정 변경, 담당 제외 알림과 Outlook에 추가 링크를 표시한 인턴핑 모바일 채팅 화면](/img/user-guide/ko/mobile/07-bot-notifications.png)

*모바일 채팅에서도 배정, 변경, 제외 알림을 확인하고 Outlook에 추가할 수 있습니다.*

### Outlook 일정 업로드하기 \{#mobile-outlook-upload}

인턴은 업로드 아이콘을 누르고 기기에 준비한 Outlook `.sql` 파일을 선택할 수 있습니다. 가져오기 전에 찾은 일정 제목과 선택 상태를 확인합니다. 모바일에서도 4MB 및 1,000건 제한이 적용됩니다.

## Outlook에 일정 추가하기 \{#mobile-add-to-outlook}

1. 일정 카드를 누릅니다.
2. 상세 패널에서 **Outlook에 추가 (.ics)**를 누릅니다.
3. 내려받은 파일을 Outlook으로 엽니다.
4. 저장할 캘린더를 확인한 뒤 저장합니다.

![인턴핑 모바일 Outlook 일정 추가 방법](/img/user-guide/ko/mobile/05-add-to-outlook.png)

*ICS 파일을 내려받는 기능이며 Outlook과 양방향으로 자동 동기화되지는 않습니다.*

## 문제 해결 \{#mobile-troubleshooting}

- **일정이 보이지 않음:** 표시 중인 주, 활성 상태 필터와 대상자 필터를 확인합니다.
- **상세 패널이 열리지 않음:** 일정 카드 자체를 누르고 Teams 탭 로딩이 끝났는지 확인합니다.
- **수정 또는 삭제가 보이지 않음:** 일정 상태, 소유권 또는 현재 역할에 해당 작업 권한이 없습니다.
- **업로드 아이콘이 보이지 않음:** 현재 화면에서는 인턴 계정에만 Outlook SQL 업로드가 표시됩니다.
- **ICS 파일이 열리지 않음:** 기기의 공유 또는 연결 앱 메뉴에서 Outlook을 선택합니다.
- **최근 변경이 보이지 않음:** 실시간 동기화가 없으므로 Teams 탭을 새로 고침합니다.
